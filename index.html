Can this run inside completely air-gapped, isolated VPC environments?

Yes. pii-scrub makes zero outbound network calls. Commercial licenses are verified completely offline using asymmetric Ed25519 cryptography embedded inside the binary. No. Unlike naive open-source tools that replace sensitive data with generic placeholders like [EMAIL] (which crashes databases on the second customer record), our Commercial Pro tier uses format-preserving deterministic pseudonymization.
